# Step 3: Flattening

After convolution, ReLU, and pooling, a convolutional neural network contains a collection of feature maps. **Flattening** reshapes these multidimensional feature maps into a one-dimensional feature vector that can be passed to a traditional fully connected, or dense, layer.

The introductory CNN pipeline is therefore:

```text
Input image
    ↓
Convolution
    ↓
ReLU
    ↓
Pooling
    ↓
Flattening
    ↓
Fully connected layers
```

## What Flattening Does

Suppose a pooled feature map is:

$$
\begin{bmatrix}
1&5\\
2&4
\end{bmatrix}
$$

Flattening reads its values in the tensor’s defined memory or indexing order and reshapes them into a vector. In a common row-major illustration:

$$
\begin{bmatrix}
1&5\\
2&4
\end{bmatrix}
\longrightarrow
\begin{bmatrix}
1\\5\\2\\4
\end{bmatrix}
$$

No arithmetic is performed. The values are not added, averaged, or learned; only their shape changes.

## Flattening Multiple Feature Maps

A convolutional layer usually produces many feature maps, one for each filter. Flattening includes the values from every channel in a single vector.

For example, suppose the pooled output contains three $2\times2$ feature maps:

$$
\text{shape}=2\times2\times3
$$

The flattened length is:

$$
2\times2\times3=12
$$

In general, for a single example with height $H$, width $W$, and $C$ channels:

$$
\text{flattened length}=HWC
$$

Thus:

$$
H\times W\times C \rightarrow HWC
$$

The precise ordering of values depends on whether a framework uses channels-last or channels-first tensor layouts. The important point is that the transformation is deterministic and retains every value exactly once.

## What Happens to the Batch Dimension?

Neural networks normally process a batch of examples. Flattening is applied independently to each example and does not combine different samples.

For a channels-last batch:

$$
N\times H\times W\times C
\rightarrow
N\times(HWC)
$$

For a channels-first batch:

$$
N\times C\times H\times W
\rightarrow
N\times(CHW)
$$

Here, $N$ is the batch size. It remains unchanged.

### Example

A batch of 32 pooled outputs, each with shape $7\times7\times64$, becomes:

$$
32\times7\times7\times64
\rightarrow
32\times3136
$$

Each of the 32 images is represented by its own vector of 3,136 features.

## Why Flatten Before a Dense Layer?

A standard dense layer expects each example to be represented as a vector. The convolutional portion of the network produces structured spatial feature maps, whereas the dense portion combines those extracted features to make a prediction.

Flattening acts as the bridge between these two parts:

```text
Feature extraction                      Classification
─────────────────────────────           ───────────────────
Convolution → ReLU → Pooling → Flatten → Dense → Output
```

The entries of the flattened vector become inputs to the dense layer. They are not separate class predictions; they are learned feature activations generated by the convolutional portion of the network.

## Does Flattening Preserve Information?

Flattening preserves all numerical values from its input. It is a reshape operation, so it does not itself discard information.

However, it removes the explicit multidimensional organization of the tensor. After flattening, the dense layer no longer processes the data using local spatial neighbourhoods. Instead, it learns separate connections from vector positions to its units.

Spatial information is not necessarily erased completely: each vector position still corresponds to a particular channel and spatial location. Nevertheless, the explicit grid structure and parameter sharing used by convolution are no longer exploited by a standard dense layer.

## Flattening Has No Trainable Parameters

A flattening layer contains no weights or biases. It only changes tensor shape:

$$
\text{parameters in Flatten}=0
$$

The dense layer that follows may contain many parameters. If the flattened input has length $D$ and the dense layer has $K$ units, then:

$$
\text{dense parameters}=DK+K
$$

The $DK$ term counts weights, and $K$ counts biases.

### Example

If a $7\times7\times512$ tensor is flattened, its length is:

$$
7\times7\times512=25{,}088
$$

Connecting it to a dense layer with 4,096 units requires:

$$
(25{,}088\times4{,}096)+4{,}096
=102{,}764{,}544
$$

parameters. This illustrates why flattening into a large dense layer can greatly increase model size and overfitting risk.

## Flattening Versus Global Average Pooling

Modern CNN architectures often use **global average pooling** instead of flattening.

Given an input with shape $H\times W\times C$, global average pooling averages every spatial location within each channel:

$$
H\times W\times C \rightarrow C
$$

For example:

$$
7\times7\times512
\xrightarrow{\text{global average pooling}}
512
$$

Compared with a flattened length of 25,088, this creates a much smaller vector and can dramatically reduce the parameter count of the classifier.

| Flattening | Global average pooling |
|---|---|
| Retains every activation | Averages each complete channel |
| Output length is $HWC$ | Output length is $C$ |
| Preserves location-specific entries | Discards within-channel spatial location |
| Can lead to very large dense layers | Usually produces a compact classifier input |
| Useful when exact spatial arrangement matters | Often improves efficiency and generalization |

Neither approach is universally superior. The choice depends on the architecture and task.

## Flattening Versus Pooling

Flattening and pooling perform different operations:

- **Pooling** summarizes local regions and may discard values to reduce spatial resolution.
- **Flattening** retains all input values but reshapes them into a vector.

For example:

$$
4\times4\times8
\xrightarrow{2\times2\text{ pooling, stride }2}
2\times2\times8
\xrightarrow{\text{flatten}}
32
$$

Pooling reduces the number of activations from 128 to 32. Flattening then reorganizes those 32 remaining activations without changing their count.

## Implementation Concept

In high-level neural-network libraries, flattening is normally represented by a dedicated layer or reshape operation. Conceptually:

```python
# Shape before flattening: (batch_size, height, width, channels)
x = flatten(x)
# Shape after flattening:  (batch_size, height * width * channels)
```

The exact API varies by framework, but the mathematical operation is the same.

## Key Takeaway

Flattening converts a stack of feature maps into one feature vector per example. It introduces no parameters and performs no calculations on the values; it simply prepares convolutional features for a dense classifier. Because the resulting vector can be very large, modern CNNs sometimes replace flattening with global pooling.

## Shape Rules

For one example:

$$
H\times W\times C \rightarrow HWC
$$

For a batch:

$$
N\times H\times W\times C
\rightarrow N\times(HWC)
$$

The batch dimension is preserved.

## Parameter Facts

- Flattening has no trainable parameters.
- It does not change the number of activation values.
- A following dense layer may have a very large number of parameters.
- Dense-layer parameters equal $(D+1)K$, where $D$ is the input length and $K$ is the number of units.
- Pooling before flattening can greatly reduce the size of the later dense layer.

## What Changes and What Stays the Same?

| Property | Result of flattening |
|---|---|
| Numerical values | Preserved |
| Number of values per example | Preserved |
| Batch size | Preserved |
| Tensor rank per example | Reduced to one dimension |
| Explicit height/width/channel axes | Removed |
| Trainable parameters | None added |

## Common Misconceptions

**“Flattening learns which features are important.”**  
It does not learn anything. The convolutional and dense layers contain learned parameters; flattening only reshapes their data.

**“Flattening combines values by adding or averaging them.”**  
Every value is copied into a vector without aggregation.

**“Flattening discards values.”**  
It preserves all input values. Pooling may discard or aggregate values before flattening.

**“The batch is flattened into one enormous vector.”**  
Each example is flattened separately. Samples in the batch remain distinct.

**“Every CNN must use flattening.”**  
Many modern CNNs use global average pooling or other aggregation methods instead.

**“Flattening itself creates millions of parameters.”**  
Flattening has zero parameters. The large parameter count comes from a dense layer connected to a long flattened vector.
